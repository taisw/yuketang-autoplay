# 雨课堂·学堂在线 自动连播（Tampermonkey 脚本）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-v27.1.0-blue.svg)](https://github.com/taisw/yuketang-autoplay/releases)

一个让你在 **雨课堂 / 学堂在线** 课程页“打开就自动学完、自动往下走”的 Tampermonkey / Violentmonkey 用户脚本，**无需改倍速、不碰 localStorage、不上传任何数据**。

> ⚠️ 仅用于个人学习自动化与课程进度管理，请遵守学校/平台规定，勿用于代刷、代考等违规用途。

---

## ✨ 功能

### 视频页（沿用已验证最稳的 v21 逻辑）
- **自动播放** → 播完或识别到「已完成」立即 `pause`（不会从头循环重播）
- **完成度驱动跳转**：达到目标完成度 / 已等满“最短等待” / 停滞超时 任一满足才跳
- **URL 硬跳**：`videoId + 1` 且 `node_id + 1`（你在 84703283→84703284 实测可用）
- **慢视频不误跳**：有 `<video>` 但时长未就绪时给 **60 秒加载宽限**
- 每节进入前**轻量清理**（session + Cache，不动 localStorage，不丢章节位置）

### 图文 / 讨论 / 作业页（v27 核心）
- **node_id 排序法**：收集页面所有章节链接的 `node_id`，取「比当前大的最小 node」，**同 node 优先跳到视频**
- 彻底绕开 v22~v25 一直搞不定的“当前项 DOM 定位”问题（不再依赖 class、不再点到“讨论区”tab、不会跳回第一节）
- 兜底链：node 排序 → 列表顺序 → 数字递增（+1~+20，带已访问防重）

### 体验
- 🔇 **强制静音增强**：`video + audio` 全部压到 0，并用 `MutationObserver` 盯住播放器**换源/重建 `<video>`**，在 `play / loadedmetadata / volumechange` 时反复校正，杜绝“静音了还突然出声”
- 章节列表**缓存**、面板 DOM 引用缓存、RAF 节流，不卡页面
- 可配置面板：播完最短等待（默认 **3s**）、跳过前等待（默认 **2s**）、目标完成度、优先跳视频开关、清空访问记录

## 📦 安装

1. 装好 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey
2. 下载脚本：[`dist/雨课堂·学堂在线-自动连播-v27.1.0.user.js`](dist/雨课堂·学堂在线-自动连播-v27.1.0.user.js)
3. 拖进浏览器 / 打开文件即安装，刷新课程页即可
4. 默认**强制静音开、自动连播开**，右下角有控制面板

> 脚本只匹配 `*.yuketang.cn`、`*.xuetangx.com` 的课程页，不会在其他网站运行。

---

## 🎛 面板说明

| 按钮 | 作用 |
|---|---|
| 🔇 取消强制静音 | 全局静音开关（恢复你原来的音量） |
| 🔍 章节诊断 | 打印 node 排序 / 列表 / 递增三项是否可用 + 耗时，排错用 |
| ⏱ 播完最短等待 | 视频播完后至少等几秒再跳（默认 3s） |
| 📄 跳过前等待 | 图文/讨论/作业判死后倒计时几秒再跳（默认 2s） |
| 🎯 目标完成度 | 完成度 ≥ 该值才允许跳（默认 95%） |
| 🎬 优先跳视频 | 关掉则非视频页也按原顺序跳，不跳过图文 |
| ▶ 立即跳下一节 | 手动触发一次 |
| 🧹 清空访问记录 | 想从第一章重跑时点 |

## 🔧 排错

| 现象 | 处理 |
|---|---|
| 视频静音后仍出声 | 点「🔍 诊断」确认是否有新增 media；多半是 **iframe 里的独立播放器**，需要给它所在域名补一条 `@match` 后重装 |
| 是“叮”的提示音而非视频声 | 可能是 Web Audio，开 Issue 我再加 `AudioContext` gain 拦截 |
| 图文页跳不动 / 下一项为 `无` | 「🔍 诊断」里看 `node排序`，若章节链接里没有 `node_id`，把控制台表格发 Issue，我改用资源 ID 排序 |
| 视频播完不跳、完成度不涨 | 切到该视频，等面板完成度出现数字；若一直 `--`，多半是上报接口被拦截，先清缓存刷新一次 |
| 想重跑整章 | 面板「🧹 清空访问记录」 |

## 🛡 隐私与安全

- 所有逻辑在**你的浏览器本地**运行，**不上传、不收集**任何账号/课程/观看数据
- 不读取、不写入 `localStorage`；清理仅限 `sessionStorage` 与浏览器 Cache
- 网络请求只有页面本身的上报逻辑，脚本不做跨站请求
